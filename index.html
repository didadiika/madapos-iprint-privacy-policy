Kebijakan Privasi

MadaPOS iPrint adalah aplikasi yang digunakan untuk menerima data transaksi dari aplikasi MadaPOS dan mencetak struk ke printer thermal Bluetooth maupun printer jaringan (LAN/Wi-Fi).

1. Informasi yang Dikumpulkan

MadaPOS iPrint tidak mengumpulkan, menyimpan, atau membagikan data pribadi pengguna.

2. Penggunaan Izin Aplikasi

Aplikasi menggunakan izin berikut:

  • Bluetooth untuk menghubungkan ke printer Bluetooth.
  • Jaringan dan Internet untuk berkomunikasi dengan printer LAN/Wi-Fi.
  • Penyimpanan lokal untuk menyimpan konfigurasi printer pada perangkat pengguna.

3. Penggunaan Data

Data transaksi hanya diproses secara lokal di perangkat pengguna untuk keperluan pencetakan dan tidak dikirim ke server mana pun.

4. Berbagi Data dengan Pihak Ketiga

Kami tidak menjual, menyewakan, atau membagikan data pengguna kepada pihak ketiga.

5. Iklan dan Analitik

Aplikasi ini tidak menampilkan iklan dan tidak menggunakan layanan analitik atau pelacakan pihak ketiga.

6. Keamanan Data

Karena data tidak dikirim ke server eksternal, informasi tetap berada di perangkat pengguna.

7. Privasi Anak

Aplikasi ini tidak ditujukan untuk anak-anak dan tidak mengumpulkan data dari anak di bawah usia 13 tahun.

8. Perubahan Kebijakan Privasi

Kebijakan privasi ini dapat diperbarui sewaktu-waktu. Perubahan akan dipublikasikan pada halaman ini.
