Kebijakan Privasi

MadaPOS iPrint adalah aplikasi yang digunakan untuk menerima data transaksi dari aplikasi MadaPOS dan mencetak struk ke printer thermal Bluetooth maupun printer jaringan (LAN/Wi-Fi).

Data yang Dikumpulkan

Aplikasi ini tidak mengumpulkan, menyimpan, atau membagikan data pribadi pengguna.

Izin Aplikasi

Aplikasi menggunakan izin Bluetooth, jaringan, dan internet hanya untuk berkomunikasi dengan printer dan menerima data transaksi.

Pihak Ketiga

Aplikasi ini tidak menggunakan layanan iklan, analitik, atau pelacakan pihak ketiga.

Keamanan Data

Kami tidak menyimpan data pengguna di server mana pun.

Perubahan Kebijakan Privasi
